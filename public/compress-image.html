How to compress image

  1. Choose a JPG, PNG, WebP or supported AVIF image.
  2. Select WebP or JPG, then choose quality or a target size such as 100 KB.
  3. Process the image, compare it with the original and download. For multiple files, use Compress a batch.

Frequently asked questions

Can I compress an image below 100 KB?

Choose Target file size and the 100 KB preset. The tool searches for an output within that limit while keeping the original dimensions. Some detailed images cannot reach it; the result will clearly say Target NOT reached.

Why can the result be larger?

A small or already optimized image can grow when re-encoded. Check the result size before downloading. PNG is lossless; JPG or WebP usually gives more control over file size.

How does batch compression work?

Select up to 20 images with a combined input below 100 MB. They are processed one at a time using the same settings. Download completed images individually or together in a ZIP; a corrupt file does not stop the other images.

Your files stay on your device

Image processing takes place in your browser. No account is needed. Downloads are new files; your original is not overwritten. Read our privacy policy.

Compress an image for email or online forms

If a website or form asks for a file below 100 KB, choose the target-size option and check the output before submitting. Some detailed images cannot reach that target without further changes. For smaller dimensions, use Resize Image first.
