Help & contact

For questions, feedback or help with a tool, email imagetoolstudio@gmail.com.

You can also report a technical problem through our GitHub issue tracker. A GitHub account is required to post there.

Open support tracker

What to include in a bug report

  • The tool name and what you expected to happen.
  • Your browser and device type.
  • The steps and settings needed to reproduce it.
  • The error message, if one appeared.

Reports are public. Do not post private images, names, email addresses or other sensitive information. A small synthetic test image is preferable.

Quick troubleshooting

If a file fails, try a smaller JPG, PNG or WebP. If a target KB size cannot be reached, increase the target or resize the image first. For ZIP downloads, wait until batch processing finishes before selecting Download ZIP.
