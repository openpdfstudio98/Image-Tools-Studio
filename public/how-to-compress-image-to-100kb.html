How to Compress an Image to 100 KB

Reduce image file size for online forms while checking the actual output and preserving enough detail.

Open Compress Image

Step-by-step instructions

  1. Check the file type and size requested by the form or website. Keep the original image.
  2. Open Compress Image and select a JPG, PNG, WebP or supported AVIF file (maximum input size 35 MB).
  3. Choose JPG or WebP and the Target file size option with the 100 KB preset.
  4. Process the image. Review the reported output size and preview before downloading. The tool may report that the target was not reached.

When the result is too large

A smaller width and height can reduce file size, but may also make text or fine details harder to read. If your application requires exact dimensions, check those requirements before resizing.

Try Resize Image and return to Compress Image to test again.

Frequently asked questions

Can every image become 100 KB?

No. Detailed images may not reach the requested size without reducing dimensions or detail.

How can I try a smaller file?

If 100 KB is not reached, try reducing dimensions using Resize Image before compressing again.

Will my image be uploaded?

Image processing runs locally in your browser. The selected image is not uploaded for processing.
